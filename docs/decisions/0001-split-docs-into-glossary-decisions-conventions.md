# Split docs into glossary, decisions, and conventions

Repo docs live under `docs/` in three homes: terms in `GLOSSARY.md`, decisions in `decisions/`, and conventions in `conventions/`, so every settled outcome has exactly one home and the `documenting` skill can file it without guessing. This departs from `domain-modeling`, which keeps `GLOSSARY.md` at the root, uses `docs/adr/`, and has no home for conventions.
