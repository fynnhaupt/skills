# Task format

The issue title names the slice, short and imperative (e.g. `Export a single report as CSV`). The body:

```md
## Behaviour

What is true once this task is done.

## Acceptance criteria

- [ ] A criterion from the spec this task covers.
```

- Copy each covered acceptance criterion from the spec word for word, so it can be traced back.
- Leave out what the spec already says; the parent link leads there.
